Serena admin app

Every page of Serena's admin app, with made-up refreshes, alerts, requests and recalls, for reviewing layout and wording. Nothing here talks to Serena, CollectionSpace or AWS. Start with Media look up, the page being redesigned.

  • Last served and First cached (layout C): under the verdict, when Serena last served the file (any size) and when it first cached it in its S3 bucket; the sizes table has both for each size, and "In Serena" Details has them too. In the app, "first cached" is the cache index's fetched-at time, which Serena already keeps. "Last served" would come from Serena's log (the "served" lines Past requests reads), so it reaches back 30 days, the log's retention; a time kept per size in Serena's tables instead would mean a write on every request, which Serena avoids.
  • Media look up, side panels (layout C): two panels on the left, "In Serena" and "In CollectionSpace now", each with its picture (Serena's cached copy; CollectionSpace's file now, which Serena doesn't keep), captioned only when there's no picture (why not) or the file is soft-deleted and a collapsible "Details": Serena's Blob, Media record, kind, access and checks; CollectionSpace's state, Blob, Media fields and when it last changed. Details start collapsed; each stays as you leave it while you look up other files. When the Media record now has a different Blob, the two pictures differ.
  • Media look up, Serena and CollectionSpace (layout C): below the sizes, a table compares Serena's records (from the last refresh) with what CollectionSpace says now about the Media record: whether it exists or is soft-deleted, which Blob it points to, the Media fields the ETL reads, and when it last changed. A row that differs is highlighted, and a line says what the next refresh will do. When Serena has no cached copy, the preview is CollectionSpace's thumbnail, which Serena doesn't keep. Serena can't tell whether the ETL will now treat the file as restricted (its rules also read the Object record), so it shows the fields, not a verdict. Try "Replaced in CollectionSpace today", "Deleted in CollectionSpace today", "The recalled image" (taken off the web since: "Approved for web" No) and "Not in the servable list"; and "CollectionSpace unreachable" in Mockup settings.

Admins see the file even when the public isn't served it (a recalled image, for example), as on the recall form. A path with no CSID Serena could look up (a bad CSID) stays plain text.
